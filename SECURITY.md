# Security Policy

## Reporting a Vulnerability

**DO NOT open a public issue.** Send findings to:

- GitHub: [Report privately](https://github.com/iktok90-design/ai-smart-contract-auditor/security/advisories/new)

We respond within 48 hours and aim for resolution within 7 days.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Active |

## Scope

- MCP server implementations
- Audit skill definitions
- Agent prompt configurations
- Report generation pipeline

## Out of Scope

- Example/demo contracts (these are intentionally vulnerable for testing)
- Third-party MCP server dependencies
