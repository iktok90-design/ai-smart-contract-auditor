# 🚀 AuditSentry v1.0.0 — Launch Notes

## Welcome to AuditSentry

After months of development at Iktok Security Labs, we're releasing the first public version of AuditSentry — an AI-powered smart contract security auditor built on Claude Code.

## What's New

- **23 specialized AI agents** for parallel contract analysis
- **45 audit commands** covering every stage of the security workflow
- **13 MCP servers** integrating industry-standard tools (Slither, Mythril, Echidna, Foundry, Hardhat)
- **Working PoC generation** — every finding comes with executable exploit code
- **Mainnet-fork simulation** — test vulnerabilities against live chain state
- **Multi-chain support** — EVM, Solana, Cosmos, Move
- **Professional reporting** — HackerOne, Bugcrowd, Immunefi, and generic formats
